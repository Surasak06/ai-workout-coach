## แนวคิดหลัก

มือถือหรือคอมทำหน้าที่แค่ **ส่งภาพจากกล้อง และแสดงผล** ส่วนโมเดลและการคำนวณทั้งหมด (ตรวจจับท่าทาง นับครั้ง ให้คะแนน) อยู่ที่ **CiRA CORE**

```
มือถือ / คอม (เว็บแอป)            HUB (Flask + SQLite)              CiRA CORE (Python+ node)
 ─ เปิดกล้อง ส่งภาพ  ───────►   รับภาพ / จัดคิว / เก็บคะแนน  ───►   YOLO11n-pose (GPU)
 ─ วาดโครงร่าง แสดงคะแนน ◄───   ส่งผลกลับ / อันดับ / ห้องดวล  ◄───   นับครั้ง ตรวจท่า ให้คะแนน
```

## โครงสร้างโปรเจค

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `cira_node.py` | โค้ดที่วางใน Python+ node ของ CiRA CORE |
| `cira_app.py` | รับภาพจาก HUB → ตรวจท่า → ส่งผลกลับ |
| `pose_source.py` | ตรวจจับคนและจุดร่างกาย (YOLO11n-pose) |
| `pushup.py`, `squat.py` | นับครั้งและตรวจท่าวิดพื้น / สควอท |
| `game.py` | จำแนกท่าและเลนของผู้เล่นสำหรับเกม |
| `config.py` | ค่าตั้งค่าทั้งหมด |
| `hub/server.py` | เซิร์ฟเวอร์ HUB (Flask + SQLite): บัญชีผู้ใช้, สตรีมภาพ, ห้องดวล, เกม, อันดับ |
| `hub/static/index.html` | เว็บแอป (หน้าเดียว) |
| `hub/start_online.bat` | เปิด HUB + ลิงก์ออนไลน์ (Cloudflare Tunnel) ให้เพื่อนเข้าเล่น |
| `esp32/` | เฟิร์มแวร์แขนกล Pan-Tilt |
| `docs/SETUP.md` | คู่มือติดตั้งและรายละเอียดเพิ่มเติม |

## วิธีรัน (ย่อ)

1. ติดตั้ง Python 3.10+ แล้ว `pip install -r requirements.txt` และ `pip install -r hub/requirements.txt`
2. เปิด `hub/start_online.bat` (หรือ `start_hub.bat` ถ้าใช้ในวงแลนเดียวกัน)
3. ใน CiRA CORE วางโค้ด `cira_node.py` ใน Python+ node แก้ `PROJECT_DIR` ให้ชี้มาที่โฟลเดอร์นี้ แล้วกด Run
4. เปิดลิงก์ที่หน้าต่าง HUB แสดง ด้วยมือถือหรือคอม → สมัครชื่อ + PIN → เริ่มฝึก

รายละเอียดเต็มอยู่ที่ [`docs/SETUP.md`](docs/SETUP.md)

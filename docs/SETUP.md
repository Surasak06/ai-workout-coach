# AI Home Workout Coach (โครงต้นแบบ)

ระบบตรวจท่าวิดพื้น นับครั้ง จับการโกงท่า วัด Time Under Tension พูดเตือนด้วยเสียง
บันทึกสถิติ และสั่งแขนกล Pan-Tilt (ESP32 + MG996R x2) ให้กล้องหันตามผู้ฝึก

```
USB Webcam ─► Pose Estimation ─► Python Logic ─► USB Serial (JSON) ─► ESP32 ─► Servo x2
              (YOLO ตอนนี้ /        │
               CiRA CORE ภายหลัง)   ├─► เสียงพูดแจ้งเตือน (TTS)
                                    └─► CSV / Google Sheets / Dashboard
```

## ไฟล์ในโปรเจค

| ไฟล์ | หน้าที่ |
|---|---|
| `config.py` | ค่าตั้งค่าทั้งหมด (เกณฑ์มุม, พอร์ต, ช่วงมุมเซอร์โว) แก้ที่นี่ที่เดียว |
| `pose_source.py` | ดึง keypoints จากกล้อง: `YoloPose` (ใช้ทดสอบตอนนี้) และ `CiraPose` (ช่องเชื่อม CiRA CORE) |
| `pushup.py` | หัวใจของระบบ: นับครั้ง, จับโกงท่า (ลงไม่ลึก / ลำตัวไม่ตรง / เร็วเกิน), วัด TUT |
| `tracker.py` | คำนวณมุม Pan/Tilt ให้กล้องตามตัวผู้ฝึก แล้วส่ง JSON ไป ESP32 |
| `voice.py` | เสียงพูดแจ้งเตือนแบบ hands-free (ไทย/อังกฤษ) |
| `stats_logger.py` | บันทึก `data/reps.csv`, `data/sessions.csv` และ Google Sheets (ถ้าเปิด) |
| `dashboard.py` | วาดกราฟพัฒนาการจาก `sessions.csv` |
| `main.py` | โปรแกรมหลัก รวมทุกส่วน |
| `esp32/pan_tilt/pan_tilt.ino` | เฟิร์มแวร์ ESP32 รับมุมแล้วขยับเซอร์โวแบบนุ่มนวล |

## เริ่มใช้งาน (ฝั่ง PC)

1. ติดตั้ง Python 3.10 ขึ้นไป แล้วเปิด Command Prompt ในโฟลเดอร์นี้
2. ติดตั้งไลบรารี
   ```
   pip install -r requirements.txt
   ```
3. ทดสอบกับเว็บแคม (ยังไม่ต่อแขนกล)
   ```
   python main.py
   ```
   ครั้งแรกจะดาวน์โหลดโมเดล `yolo11n-pose.pt` (~6 MB) อัตโนมัติ
4. ตั้งกล้องให้เห็น **ด้านข้าง** ของผู้ฝึก (เห็นไหล่ ศอก ข้อมือ สะโพก ข้อเท้า ข้างเดียวกันครบ)
5. ปุ่มลัด: `q` จบเซตและบันทึก, `r` เริ่มนับใหม่, `c` กล้องกลับกึ่งกลาง
6. ดูกราฟ: `python dashboard.py`

ทดสอบกับคลิปวิดีโอแทนกล้อง: `python main.py --source pushup.mp4`

## หลักการตัดสินท่า (ปรับได้ใน `config.py`)

| สิ่งที่วัด | วิธีวัด | เกณฑ์เริ่มต้น |
|---|---|---|
| นับ 1 ครั้ง | มุมศอก (ไหล่-ศอก-ข้อมือ) จากเหยียด → งอ → เหยียด | บน > 155°, ล่าง < 95° |
| ลงไม่ลึก (โกง) | มุมศอกต่ำสุดไม่ถึงเกณฑ์ล่าง | ไม่นับครั้งนั้น |
| ลำตัวไม่ตรง (โกง) | มุม ไหล่-สะโพก-ข้อเท้า | ต่ำกว่า 155° = สะโพกตก/โก่ง ไม่นับ |
| เร็วเกินไป | เวลาทั้งครั้ง | ต่ำกว่า 1.2 วินาที (นับ แต่เตือน) |
| Time Under Tension | เวลาช่วงลง + ช่วงขึ้น แยกที่จุดศอกงอที่สุด | บันทึกทุกครั้ง |

ระบบเลือกข้างของร่างกาย (ซ้าย/ขวา) ที่กล้องเห็นชัดกว่าให้อัตโนมัติ

## ต่อฮาร์ดแวร์

```
แหล่งจ่าย 5V (≥3A) ──+5V──► สายแดง Servo Pan และ Servo Tilt
                    └─GND──► สายน้ำตาล Servo ทั้งสอง ──► GND ของ ESP32 (กราวด์ร่วม สำคัญมาก)
ESP32 GPIO 18 ──► สายสัญญาณ (ส้ม) Servo Pan   (ส่าย ซ้าย-ขวา)
ESP32 GPIO 19 ──► สายสัญญาณ (ส้ม) Servo Tilt  (ก้ม-เงย)
ESP32 USB     ──► PC
```

- **ห้าม** จ่ายไฟเซอร์โว MG996R จากขา 5V/VIN ของ ESP32 กระแสไม่พอ บอร์ดจะรีเซ็ตเอง
- อัปโหลดเฟิร์มแวร์: Arduino IDE → ติดตั้งบอร์ด ESP32 และไลบรารี **ESP32Servo** → เปิด `esp32/pan_tilt/pan_tilt.ino` → เลือก ESP32 Dev Module → Upload
- ทดสอบเฟิร์มแวร์เดี่ยว ๆ: เปิด Serial Monitor (115200, Newline) พิมพ์ `{"pan":60,"tilt":90}` แล้วกด Enter
- ต้องปิด Serial Monitor ก่อนรัน Python เพราะใช้พอร์ตเดียวกัน
- รันพร้อมแขนกล: `python main.py --serial COM3` (ดูเลข COM ใน Device Manager)

ถ้ากล้องหมุน **หนี** คนแทนที่จะตาม ให้สลับ `INVERT_PAN` หรือ `INVERT_TILT` ใน `config.py`
ถ้ากล้องสั่นไปมา ให้ลด `TRACK_GAIN` หรือเพิ่ม `TRACK_DEADBAND`

## การเชื่อม CiRA CORE (ขั้นต่อไป)

ตอนนี้ใช้ YOLO pose แทนไปก่อน เพื่อให้ทำ logic ทั้งหมดและทดสอบได้ทันที
ส่วนอื่นทุกส่วนรับข้อมูลแค่ dict ของ keypoints เท่านั้น จึงสลับไป CiRA CORE ได้โดยแก้ `pose_source.py` ไฟล์เดียว

ต้องเช็กใน CiRA CORE ว่า:
1. node pose estimation ส่งผลออกมาเป็นอะไร (กี่จุด เรียงลำดับแบบไหน เป็นพิกเซลหรือสัดส่วน 0-1)
2. เขียน Python ใน flow ได้ไหม → ถ้าได้ เอา `pushup.py`, `tracker.py` ไปเรียกใน node นั้นได้เลย
3. หรือส่งข้อมูลออกนอกโปรแกรมได้ (UDP/MQTT/ไฟล์) → ใช้คลาส `CiraPose` ที่รับ JSON ทาง UDP แล้วตั้ง `POSE_BACKEND = "cira"`

## แผนงานแนะนำ

| สัปดาห์ | งาน | เสร็จเมื่อ |
|---|---|---|
| 1 | รัน `main.py` กับเว็บแคม จูนเกณฑ์มุมจากการวิดพื้นจริง 3-4 คน | นับถูก ≥ 90% |
| 2 | ประกอบ Pan-Tilt, อัปโหลดเฟิร์มแวร์, ทดสอบตามคน | กล้องตามได้ไม่สั่น |
| 3 | เชื่อม CiRA CORE แทน YOLO | ผลเท่าเดิมหรือดีกว่า |
| 4 | เสียงไทย, Google Sheets / Dashboard, ถ่ายคลิปเดโม | เดโมครบทั้งระบบ |

ต่อยอดได้: เพิ่มท่า squat / plank (เขียนคลาสใหม่แบบเดียวกับ `PushUpAnalyzer`), เก็บผลหลายผู้ใช้, แจ้งเตือนเมื่อฟอร์มเริ่มเสียจากความล้า

## โหมดเกม: คะแนน แรงค์ และแข่งกับเพื่อน (HUB)

```
เครื่องเพื่อน A (CiRA) ─┐
เครื่องเพื่อน B (CiRA) ─┼──Wi-Fi──► HUB (hub/server.py บนโน้ตบุ๊กเครื่องหนึ่ง) ◄── มือถือทุกเครื่อง (เปิดเว็บ)
เครื่องคุณ (CiRA)     ─┘
```

**1. เปิด HUB (เครื่องเดียว)**
- ดับเบิลคลิก `hub\start_hub.bat` (ครั้งแรกจะติดตั้ง flask ให้เอง)
- ถ้า Windows Firewall ถาม ให้กด **Allow** และติ๊ก **Private networks**
- หน้าต่างจะแสดงลิงก์ เช่น `http://192.168.1.23:5000` → เปิดลิงก์นี้ในมือถือที่ต่อ Wi-Fi เดียวกัน

**2. ตั้งค่าเครื่องที่รัน CiRA (ทุกเครื่องที่จะเล่น)** แก้ใน `config.py`
```python
PLAYER_NAME = "ชื่อคุณ"
HUB_URL = "http://192.168.1.23:5000"    # ลิงก์จากข้อ 1
```
แล้วกด Stop → Start ที่ Python+

**3. เล่น**: วิดพื้นตามปกติ ระหว่างเล่นมือถือจะเห็นแท็บ "สด" พอจบเซต (คลิปจบ / ไม่เห็นคน 10 วินาที / กด Stop → Start)
ผลจะถูกส่งไป HUB และบนภาพ CiRA จะขึ้น `+XP` กับแรงค์

**กติกาคะแนน** (แก้ได้ที่ต้นไฟล์ `hub/server.py`)
- ทำถูก 1 ครั้ง = 10 XP (ครั้งที่โกงท่าไม่ได้คะแนน)
- คุมจังหวะดี (TUT 2-4 วินาที) +5 XP ต่อครั้ง
- ทั้งเซตทำถูก ≥ 90% (อย่างน้อย 5 ครั้ง) +20 XP
- ถึงเป้ารายวัน 30 ครั้ง +50 XP
- แรงค์: Bronze 0 → Silver 500 → Gold 1,500 → Platinum 3,500 → Diamond 7,000 XP

ถ้า Wi-Fi หลุดหรือ HUB ปิด ผลจะถูกเก็บไว้ใน `data/pending_uploads.jsonl` แล้วส่งให้เองตอนจบเซตครั้งถัดไป
ข้อมูลทั้งหมดของ HUB อยู่ในไฟล์ `hub/coach.db` (ลบทิ้ง = เริ่มคะแนนใหม่หมด)


## โหมดเว็บ (ใช้งานหลัก): เว็บเปิดกล้อง → CiRA ประมวลผลอยู่หลังบ้าน

```
[หน้าเว็บ: เลือกชื่อ → กดเริ่ม → เปิดกล้องเครื่องนั้น] ──ภาพ──► [HUB] ◄──ขอภาพ/ส่งผล── [CiRA: Python+]
        ▲  เห็นโครงกระดูก / จำนวนครั้ง / เสียงพูด / XP                                (กด Run ครั้งเดียว)
        └───────────────────────────────── ผล ─────────────────────────────────────────┘
```

- เล่นพร้อมกันได้ 2 คน (แก้ `MAX_STREAMS` ใน `hub/server.py`)
- เพื่อนไม่ต้องติดตั้ง CiRA แค่เปิดเว็บด้วยลิงก์ `https://<IP โน้ตบุ๊ก>:5443` แล้วกดผ่านคำเตือนครั้งแรก
  (Chrome/Edge: "ขั้นสูง / Advanced" → "ดำเนินการต่อ") เพราะ browser เปิดกล้องได้เฉพาะเว็บ https หรือ 127.0.0.1
- บนโน้ตบุ๊กที่รัน HUB ใช้ `http://127.0.0.1:5000` ได้เลย
- แขนกล Pan-Tilt ขยับตามเฉพาะผู้เล่นที่เปิดเว็บบนโน้ตบุ๊กเครื่องที่ต่อ ESP32
- เสียงพูดออกจากลำโพงของเครื่องที่เล่น (ถ้าไม่มีเสียงไทย ให้เพิ่ม Thai ใน Windows Settings → Time & language → Speech)

**ตั้งค่า (ทำครั้งเดียว)**
1. `config.py`:  `INPUT_SOURCE = "web"` และ `HUB_URL = "http://127.0.0.1:5000"`
2. ดับเบิลคลิก `hub\start_hub.bat` (เปิดค้างไว้)
3. CiRA: flow เดิม (Button Run → VideoFile → Python+ → Debug) กด Run ครั้งเดียว
   - ในโหมดเว็บ Python+ จะไม่ใช้ภาพจาก VideoFile (ใช้แค่เป็นตัวจังหวะ) จอ Debug จะแสดงภาพจากเว็บแทน
4. เปิดเว็บ → แท็บ "ออกกำลังกาย" → ใส่ชื่อ → เลือกกล้อง → เริ่ม

**กลับไปทดสอบด้วยคลิปใน CiRA แบบเดิม:** ตั้ง `INPUT_SOURCE = "cira"` แล้ว Stop → Start ที่ Python+


## เล่นกับเพื่อนที่อยู่คนละที่ (ผ่านอินเทอร์เน็ต)

ดับเบิลคลิก `hub\start_online.bat` แทน `start_hub.bat`
- จะเปิด 2 หน้าต่าง: HUB และหน้าต่าง "ลิงก์ออนไลน์" (เปิดค้างไว้ทั้งคู่)
- ครั้งแรกจะดาวน์โหลดโปรแกรม cloudflared (~60 MB) มาไว้ในโฟลเดอร์ hub ให้เอง
- หน้าต่างลิงก์จะแสดง `https://xxxx.trycloudflare.com` → ส่งให้เพื่อน (เปิดได้ทุกที่ ไม่มีคำเตือน กล้องเปิดได้)
- ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่ และดูลิงก์ล่าสุดได้ในไฟล์ `hub\online_link.txt` หรือบนหน้าเว็บของเครื่องคุณ (แท็บออกกำลังกาย)
- ใช้เน็ตบ้านของคุณ: เพื่อน 1 คน ≈ 0.5 MB/s ขาเข้า

## เลเวล แรงค์ และเกมเลนท่าทาง (v8)
- **เลเวล (Lv)** มาจาก EXP สะสม: เลเวลถัดไปใช้ 100 × เลเวลปัจจุบัน
- **แรงค์** มาจากแต้มแรงค์ (RP) แยกจาก EXP: ดวลชนะ +25 / เสมอ +5 / แพ้ −15 (ไม่ต่ำกว่า 0) และเกมได้สูงสุด +20 ต่อเกม
  Bronze 0 · Silver 100 · Gold 250 · Platinum 450 · Diamond 700
- หน้าอันดับมี 2 แท็บ: **อันดับการฝึก** (เรียงตาม EXP แต่เห็นแค่เลเวลของคนอื่น) และ **อันดับแรงค์** (เรียงตาม RP เห็น RP ของตัวเองเท่านั้น)
- **ฝึกท่า** มี 2 โหมด: *มือใหม่* (คลิปโค้ชมุมซ้ายบน + เสียงอธิบายท่า แล้วทำตาม) และ *ฝึกจริง* (นับครั้ง เก็บ EXP) — จอเป็นกล้องเต็มจอ นับแค่จำนวนครั้ง
- ปุ่ม **สลับกล้องหน้า/หลัง** อยู่มุมขวาบน ทั้งตอนฝึก และตอนอยู่ในห้องดวล
- **ดวล**: สร้างห้องก่อน แล้วเจ้าของห้องเลือกท่าจากการ์ดรูป
- **เกมเลนท่าทาง** (`game.py` ใน CiRA): การ์ดท่า (ชูมือ / กางแขน / มือเท้าเอว / สควอท) ไหลลงมา 3 เลน ขยับไปเลนนั้นแล้วทำท่าให้ทันตอนการ์ดถึงเส้น
  CiRA บอกท่าและเลนของผู้เล่น HUB เป็นคนตัดสินว่าโดนหรือไม่ เว็บแค่แสดงผล
- **จอใหญ่ + มือถือเป็นกล้อง**: คอมกด "จอใหญ่ + มือถือเป็นกล้อง" → มือถือสแกน QR (หรือเปิดเว็บ → เกม → ใส่รหัส 4 หลัก)
  มือถือส่งภาพไป CiRA จอคอมแสดงเกม + ภาพจากกล้องมือถือ (มือถือไม่ต้องล็อกอิน ผลบันทึกในชื่อคนที่เปิดจอคอม)
- รูปตกแต่ง (เหรียญ, การ์ดเกม, ปกเกม): ดู `hub/static/img/README.txt`

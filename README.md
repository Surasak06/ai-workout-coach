## แนวคิดหลัก

มือถือหรือคอม **ส่งภาพจากกล้องและแสดงผลเท่านั้น** ส่วนโมเดลและการคำนวณทั้งหมด (หาจุดบนร่างกาย นับครั้ง ตรวจท่า ให้คะแนน ตัดสินดวลและเกม) อยู่ที่ **CiRA CORE** และ **HUB**
มือถือรุ่นเก่าจึงได้ผลเท่ากับรุ่นใหม่ และผู้เล่นแก้คะแนนจากเบราว์เซอร์ไม่ได้

```
 มือถือ / คอม (เว็บแอป)             HUB  (Flask + SQLite)                 CiRA CORE  (Python+ node)
 ┌──────────────────────┐  HTTPS   ┌───────────────────────────┐  HTTP    ┌──────────────────────────┐
 │ เปิดกล้อง → JPEG     │ ───────► │ คิวภาพ (เก็บแค่ภาพล่าสุด) │ ◄─────── │ GET  /api/work  (ขอภาพ)  │
 │ วาดโครงกระดูก        │          │ บัญชี · อันดับ · ห้องดวล  │          │ YOLO11n-pose → 17 จุด    │
 │ ตัวเลข · เสียงไทย    │ ◄─────── │ ตัดสินดวล/เกม · ให้แต้ม   │ ◄─────── │ POST /result (ผล JSON)   │
 └──────────────────────┘  ผลกลับ  └───────────────────────────┘          └──────────────────────────┘
            ▲  ผ่าน Cloudflare Tunnel (ลิงก์ออนไลน์) หรือวงแลนเดียวกัน
```

| ช่วง | โปรโตคอล | ส่งอะไร |
|---|---|---|
| เบราว์เซอร์ → HUB | HTTPS (Cloudflare Tunnel, HTTP/2) หรือ HTTP 5000 / HTTPS 5443 ในวงแลน | `POST /api/stream/<sid>/frame` ภาพ JPEG ทีละเฟรม · คำตอบคือผลล่าสุด (JSON) |
| CiRA ↔ HUB | HTTP polling ที่ `127.0.0.1:5000` | `GET /api/work` ได้ภาพ + header (`X-Stream`, `X-Exercise`, …) · `POST /api/work/<sid>/result` ส่งผล |
| สายวัดหัวใจ → เบราว์เซอร์ | Bluetooth LE (Web Bluetooth) | บริการ `heart_rate` (ไม่บังคับ) |

## วิธีติดตั้งและรัน

**ต้องมี:** Windows · Python 3.10+ · CiRA CORE (มี Python+ node และ `ultralytics`) · ไฟล์ `yolo11n-pose.pt` ในโฟลเดอร์โปรเจกต์

1. ตั้งค่าใน `config.py`: `INPUT_SOURCE = "web"` และ `HUB_URL = "http://127.0.0.1:5000"`
2. ดับเบิลคลิก `hub\start_online.bat` (ติดตั้ง `flask` `cryptography` ให้เอง)
   - ครั้งแรกจะดาวน์โหลด `cloudflared` มาให้ แล้วแสดงลิงก์ `https://….trycloudflare.com`
   - ใช้แค่ในวงแลน: ใช้ `hub\start_hub.bat` แล้วเปิด `https://<IP คอม>:5443`
3. ใน CiRA CORE ต่อ flow: **Button Run → VideoFile → Python+ → Debug**
   - วางโค้ด `cira_node.py` ใน Python+ แก้ `PROJECT_DIR` ให้ชี้มาที่โฟลเดอร์นี้ แล้วกด Run
   - ในโหมดเว็บ VideoFile เป็นแค่ตัวจับจังหวะให้ Python+ ทำงานทุกเฟรม ภาพจริงดึงจาก HUB
4. เปิดลิงก์ด้วยมือถือหรือคอม → สมัครชื่อ + PIN → เลือกท่า → ตั้งกล้องตามรูปตัวอย่าง → เริ่ม

**อัปเดตโค้ด:** แก้ `server.py` → ปิดแล้วเปิด `.bat` ใหม่ · แก้ไฟล์ Python ฝั่ง CiRA → Stop → Run · แก้เว็บ → Ctrl+F5
(`CODE_VERSION` ใน `cira_app.py` ต้องเท่ากับ `CIRA_VER` ใน `index.html` ไม่อย่างนั้นเว็บจะเตือนให้รีสตาร์ท CiRA)

รายละเอียดเพิ่มเติม: [`docs/SETUP.md`](docs/SETUP.md)

## ข้อจำกัดที่รู้อยู่

- ลิงก์ออนไลน์เปลี่ยนทุกครั้งที่เปิดใหม่ (ใช้ Cloudflare quick tunnel)
- ฝึกพร้อมกันได้ 2 คน (`MAX_STREAMS`) เพราะใช้ GPU ตัวเดียว
- ต้องตั้งกล้องให้เห็นข้อต่อที่ท่านั้นใช้ครบ กล้องเห็นแค่ 2 มิติ มุมกล้องเอียงทำให้มุมเพี้ยน
- เสียงไทยขึ้นกับเครื่องผู้ใช้ · iPhone ใช้ Web Bluetooth ไม่ได้
- ทดสอบด้วย CiRA จำลองและ Playwright แล้ว ยังต้องทดสอบกับผู้ใช้จริงจำนวนมากขึ้น

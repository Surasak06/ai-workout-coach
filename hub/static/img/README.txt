รูป / คลิป ที่ตกแต่งเองได้ (ทำใน Photoshop แล้ววางไฟล์ตามชื่อนี้)
ถ้ายังไม่มีไฟล์ เว็บจะใช้ภาพวาดสำรองให้อัตโนมัติ ไม่ต้องแก้โค้ด
หลังวางไฟล์: กด Ctrl+F5 ที่เว็บ (ไม่ต้องรีสตาร์ท HUB)

1) รูปการ์ดเลือกท่า   hub/static/img/ex/<ชื่อท่า>.jpg
   ขนาดแนะนำ 800 x 1000 px (แนวตั้ง 4:5)  ไฟล์ไม่เกิน ~200 KB
   ชื่อไฟล์: pushup.jpg  squat.jpg  plank.jpg  lunge.jpg  jumpingjack.jpg  stretch.jpg
   เคล็ดลับ: ให้คนอยู่ครึ่งบนของภาพ ส่วนล่าง 25% เว็บจะทับด้วยแถบมืด + ชื่อท่า

2) เหรียญแรงค์          hub/static/img/rank/<แรงค์>.png
   ขนาด 256 x 256 px พื้นหลังโปร่งใส (PNG)
   ชื่อไฟล์: bronze.png  silver.png  gold.png  platinum.png  diamond.png
   ใช้ที่: หน้าแรก, ตารางอันดับ, โปรไฟล์, หน้าสรุปผล (ตอนขึ้นแรงค์)

3) รูปสัตว์ (ระดับความสามารถตอนจบเซต)   hub/static/img/animal/<สัตว์>.png
   ขนาด 512 x 512 px พื้นหลังโปร่งใส
   ชื่อไฟล์ (ช้า -> เร็ว): turtle.png  panda.png  cat.png  wolf.png  tiger.png  cheetah.png

4) คลิปโค้ชสอนท่า (โหมด "มือใหม่" เล่นมุมซ้ายบนของจอ)   hub/static/video/<ชื่อท่า>.mp4
   ชื่อไฟล์: squat.mp4  pushup.mp4
   แนะนำ: แนวนอน 1280x720 หรือ 960x540, H.264, ไม่มีเสียงก็ได้ (เว็บปิดเสียงคลิป ใช้เสียงโค้ช AI แทน)
   ความยาว 6-15 วินาที ทำท่าช้า ๆ 2-3 ครั้ง (ลง 2 วิ ขึ้น 1 วิ) ระบบจะเล่นวนซ้ำ
   ถ่ายมุมเดียวกับที่ผู้เล่นวางกล้อง (สควอท: ด้านข้างหรือด้านหน้า, วิดพื้น: ด้านข้าง)

5) เหรียญรางวัล (หน้าโปรไฟล์)   hub/static/img/badge/<ชื่อ>.png
   ขนาด 256 x 256 px พื้นหลังโปร่งใส (PNG)
   first_set.png   เซตแรก
   perfect.png     เซตที่คะแนนท่า 90 ขึ้นไป
   set20.png       ทำได้ 20 ครั้งในเซตเดียว
   total100.png    รวม 100 ครั้ง
   total1000.png   รวม 1,000 ครั้ง
   daily_goal.png  ทำครบเป้าวันนี้
   streak3.png     ฝึกต่อเนื่อง 3 วัน
   streak7.png     ฝึกต่อเนื่อง 7 วัน
   (เหรียญที่ยังไม่ได้ เว็บจะแสดงเป็นสีเทาเอง ใช้รูปเดียวกันได้)

6) เกมเลนท่าทาง   hub/static/img/game/<ชื่อ>.png
   cover.png   รูปปกเกมในหน้าเมนูเกม (สี่เหลี่ยมจัตุรัส 512 x 512)
   การ์ดท่าที่ไหลลงมา (512 x 512 พื้นหลังโปร่งใส รูปคน/ไอคอนสีขาวจะเห็นชัดบนการ์ดสี):
   up.png      ชูมือ
   t.png       กางแขน
   hips.png    มือเท้าเอว
   squat.png   สควอท

7) รูปโปรไฟล์ของผู้เล่น  ไม่ต้องวางเอง — อัปโหลดจากหน้าโปรไฟล์ในเว็บ (เก็บที่ hub/static/uploads/avatars/)

8) การ์ดเลือกโหมดฝึก (หน้า "ฝึก" ก่อนเลือกท่า)   hub/static/img/mode/<ชื่อ>.jpg
   ขนาดแนะนำ 800 x 1000 px (แนวตั้ง 4:5)
   beginner.jpg   การ์ด "มือใหม่"
   pro.jpg        การ์ด "มือโปร"
   ส่วนล่างของการ์ดเว็บจะทับด้วยแถบมืด + ชื่อโหมด (ไม่ต้องใส่ตัวหนังสือในรูป)
